# 台股營收行事曆

列出台灣所有上市、上櫃個股，並提供：

- **股票列表**：收盤價、漲跌幅、成交量、市值、最新月營收與年增率、營收公布日；可依市場／產業篩選、點欄位排序、加入自選（★）。
- **條件選股**：每個條件可設為「必要」（全部符合才列出）、「加分」（不排除，只決定排名先後）或「不用」；條件包含月營收連續三個月創高、單月營收月增、收盤創近 20 日新高、站上 5/10/20 日均線、最近一日漲停、EPS 為正、均線多頭排列、月營收年增。
- **產業排行榜**：每個產業列出前 10 名，可切換排名依據（市值、月營收、月營收年增率、累計營收年增率、漲跌幅、成交量）、排序方向與市場。
- **營收行事曆**：月曆檢視每天有哪些公司公布營收，點日期可看清單；頁面上方會顯示最近公布營收的公司。
- **搜尋框**：輸入代號或名稱（支援鍵盤上下鍵與 Enter）。
- **技術圖**：點任一檔股票開啟 K 線圖＋成交量，可切換 MA5、MA10、MA20、MA60、MA120 均線，並可選 3 月／6 月／1 年／全部區間。

## 本機使用

```bash
python3 scripts/fetch_data.py      # 抓資料（第一次會回補約 14 個月股價，需 30 分鐘以上）
python3 -m http.server 8000        # 啟動網頁伺服器
# 開啟 http://localhost:8000
```

只需要 Python 3 標準函式庫，不必安裝其他套件。

## 資料來源

| 資料 | 來源 |
|---|---|
| 上市／上櫃公司清單 | 證交所 OpenAPI `t187ap03_L`、櫃買中心 OpenAPI `mopsfin_t187ap03_O` |
| 月營收 | 證交所 OpenAPI `t187ap05_L`、櫃買中心 OpenAPI `mopsfin_t187ap05_O` |
| 累計 EPS | 證交所 OpenAPI `t187ap14_L`、櫃買中心 OpenAPI `mopsfin_t187ap14_O` |
| 日 K 線 | 證交所 `MI_INDEX` 每日收盤行情、櫃買中心 `dailyQuotes` |

股價為未還原權息的原始價格。

## 營收公布日怎麼來的

公開資料只提供「最新一期營收」，沒有每家公司的公布日期。每天自動執行 `fetch_data.py` 時，若發現某公司出現新月份的營收，就把當天記為公布日（存在 `data/revenue_dates.json`），行事曆只顯示這些實際紀錄。

## 自動更新（GitHub Actions + GitHub Pages）

`.github/workflows/update-data.yml` 會每天台灣時間約 16:10 與 21:40 抓取最新資料、提交回 repo 並部署到 GitHub Pages。
啟用方式：合併到預設分支後，到 **Settings → Pages** 把 Source 設為 **GitHub Actions**，再到 **Actions** 分頁手動執行一次。
